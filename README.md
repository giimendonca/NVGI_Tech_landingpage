# NVGI Tech | Landing page

Landing page institucional da NVGI Tech, desenvolvida com React, Vite, Framer Motion e Lucide.

## Requisitos

- Node.js 20.19+ ou 22.12+
- npm

## Executar localmente

```bash
npm install
npm run dev
```

O Vite exibirá o endereço local no terminal.

## Build de produção

```bash
npm run build
npm run preview
```

Os arquivos finais são gerados em `dist/`.

## Personalização antes de publicar

- Substituir o link provisório do GitHub na seção de contato pelo canal oficial da NVGI Tech.
- Revisar os textos e o status dos projetos apresentados.
- Adicionar a logo oficial quando os arquivos finais estiverem prontos. O wordmark atual é temporário e feito em CSS.
- Atualizar favicon e imagens sociais (Open Graph) quando a identidade visual final for adicionada.

## Estrutura

- `src/App.jsx`: seções, conteúdo e componentes.
- `src/styles.css`: identidade visual, responsividade e animações.
- `src/main.jsx`: inicialização do React.
- `index.html`: metadados e fontes.
